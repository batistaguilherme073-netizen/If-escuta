# IF Escuta: Your Well-being Hub

PROMPT COMPLETO – DESENVOLVIMENTO DO APLICATIVO "IF ESCUTA"

Objetivo Geral

Desenvolva um aplicativo multiplataforma completo, moderno e totalmente funcional chamado IF Escuta, compatível com Android, iOS, Web, Desktop, tablets e smartphones.

O objetivo do aplicativo é fortalecer a integração entre estudantes e profissionais dos Institutos Federais da Bahia, oferecendo uma plataforma de acolhimento, acompanhamento, educação em saúde mental e comunicação institucional para auxiliar estudantes que apresentem Transtornos Mentais Comuns (TMC), como ansiedade, depressão e estresse.

O aplicativo não substitui atendimento médico ou psicológico. Em situações de risco, deve orientar imediatamente o usuário a procurar ajuda especializada e disponibilizar acesso rápido aos serviços oficiais de emergência.
